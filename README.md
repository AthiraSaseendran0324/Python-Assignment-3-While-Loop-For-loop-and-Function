##  Assignment Tasks

### 1. Number Guessing Game

A simple number guessing game where:

- The computer generates a random number between 1 and 10.
- The user gets 3 attempts to guess the number.
- "continue" is used when the entered number is outside the valid range.
- "break" is used when the correct number is guessed.
- "while...else" is used when all attempts are completed.

### 2. Multiplication Table Generator

A program that:

- Takes a number from the user.
- Uses a "for" loop and "range()" function.
- Displays the multiplication table from 1 to 10.

### 3. BMI Calculator

A BMI calculator using a function.

The program:

- Takes weight in kilograms.
- Takes height in meters.
- Calculates BMI using the formula:

**BMI = Weight (kg) / (Height (m) × Height (m))**

- Uses a function with parameters.
- Returns the calculated BMI.
